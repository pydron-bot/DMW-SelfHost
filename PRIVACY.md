# Privacy Policy

_Last updated: 2026-09-10_

This is a personal, single-user project ("the App") operated by its owner
("we", "us"). It is not a commercial product and is not offered to other users.

## What we access

With the owner's explicit authorization through Google OAuth, the App accesses:

- **Gmail** — message content, metadata, and labels for the owner's own account.
- **Google Calendar** — event and calendar data for the owner's own account.

The App only acts on the account of the person who authorized it.

## How we use it

Google user data is used solely to provide assistant features the owner requests
in the moment — for example: summarizing recent email, drafting or sending a
reply, listing upcoming events, or creating a calendar entry.

To generate those responses, the relevant message or calendar content is sent to
the App's language-model provider, **Anthropic**
(<https://www.anthropic.com/legal/privacy>), for processing. It is not used to
train models.

## Storage and retention

- **OAuth tokens** are stored on the owner's private server and kept until access
  is revoked.
- **Email and calendar content** is processed only to answer a request and is not
  stored in a database. Summaries or notes the owner explicitly asks the App to
  save are written to the owner's own private notes.

## Sharing

We do not sell Google user data, and we do not share it with third parties except:

- **Google** — as the API provider.
- **Anthropic** — as the language-model provider that processes content to produce
  responses.

## Limited Use disclosure

The App's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at <https://myaccount.google.com/permissions>.
